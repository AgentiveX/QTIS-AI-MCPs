# Security

Report security issues privately to [krish@agentivex.ai](mailto:krish@agentivex.ai).
Include the affected public endpoint, a safe reproduction, and the approximate
time. Do not send patient data or live credentials. Do not open a public issue
for a vulnerability involving access to private records.

The hosted connector uses each staff member's own QTIS permissions. This
repository contains public metadata and client examples. It must never contain
passwords, bearer/refresh tokens, OAuth client secrets, deployment credentials,
or real patient records.

Use the least access needed, approve exact changes, and revoke connections
when they are no longer needed. Public issues are for documentation and
non-sensitive integration questions.
